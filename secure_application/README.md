# CryptoLabX Cryptocurrency Wallet

## Description

This project implements a small console-based cryptocurrency wallet
application as part of Assignment 3.

The application does not implement actual cryptographic operations.
It focuses on basic wallet and transaction management functionality.

## Functionalities

The application provides the following features:

1. Wallet creation
2. Balance inquiry
3. Transaction history
4. Transaction requests
5. Login and logout
6. Basic administrative access

## Technology

- Programming Language: Python
- Interface: Console-based
- Data Storage: JSON files

## Intentionally Introduced Vulnerabilities

Three vulnerabilities were intentionally introduced for educational
purposes:

1. Broken Access Control
2. Insecure Session Handling
3. Hardcoded Secrets
